PHASES

1. Migration plan + source-to-target mapping document (scope, type mapping, risks, rollback, success criteria)
2. Profile the source (row counts, null counts, distinct counts, min/max/sum, orphan checks, duplicate PKs) and save as a baseline
3. Extract with Python (pandas + SQLAlchemy + pymysql), write files plus a manifest with row counts and per-row hashes; upload to a Databricks Volume
4. Bronze: raw copy as strings (no cleaning), add _ingest_ts, _source_file, _batch_id, write to Delta, loop over tables using a config list
5. Silver: cast types, trim/standardize, handle empty strings vs nulls, dedupe with window functions, enforce rules, quarantine bad rows into <table>_rejects with reject_reason, check referential integrity; inject dirty data into a copy of the source to test this
6. Gold: business tables (monthly revenue by store, top 10 films by rentals, customer lifetime value, inventory utilization, late-return analysis), each cross-checked against the same query run directly on MySQL
7. Validation framework: one reusable config-driven notebook writing to a validation_results Delta table (run_id, run_ts, table, layer, check_name, expected, actual, status, details). Checks: row count, row-level hash, missing/extra keys, null counts, distinct counts, numeric aggregates, date ranges, duplicates, referential integrity, Gold vs MySQL. Then deliberately break the target (delete rows, change values, insert duplicates, alter decimals) and prove the framework catches every defect
8. Make it repeatable: Databricks Job with task dependencies (Bronze -> Silver -> Gold -> Validate), parameterized batch_id, idempotent Silver loads with MERGE INTO, logging
9. Documentation: README with architecture diagram, results table, data quality issues found, defect-injection results, lessons learned; add a Projects entry to my resume
